# 12.0.0.19.1 (build 437) — 261004, same-day follow-up to 19.0

Three changes from dogfooding build 436, all fork-side; no upstream movement.

## Today synthesis: real Now / Next sections, Watch retired

19.0's bolded lead-ins rendered as one Now bullet, several Next bullets and a Watch
bullet. The default prompt now asks for **Now** and **Next** as section lines with
2-4 bullets each beneath, Now re-specified as the richer half (state of being,
interpretation never readout, causal reads allowed and flagged, and it remains the
stated premise for Next). Watch is gone as a section: a genuinely forming watchout
(climbing RHR + sagging HRV + elevated resp) rides inside Now as its own bullet.
Prompt pins updated: the blanket "No headings" pin became the exact two-section
contract. Override note: an edited prompt shadows the default — Reset to default.

## Trends: exactly one insight per day

19.0 still produced one finding per metric — a tour of charge, sleep, effort. The
default now outputs ONE daily insight: a bolded claim plus one or two sentences of
the so-what, an INTERPRETATION rather than a restated stat, novelty rotating day to
day ("yesterday's insight must not be today's"), and nothing else. The per-day
re-ask (subject carries the local day key) is unchanged from 19.0.

## The Start-workout offer is toggleable

Upstream v12 pinned the idle "Start workout" button above Today's arrangeable
sections with no way to hide it. New Settings toggle (default ON, beside
Auto-detect workouts), honoured by BOTH Today implementations. Off hides only the
idle offer — an in-progress workout's indicator always shows, and the Workouts tab
keeps its own Start control.

## What the next log must show

Unchanged from 19.0 (docs/releases/fork/v12.0.0.19.0.md): the morning-settle
criteria are still the open verification. This build adds nothing engine-side.
