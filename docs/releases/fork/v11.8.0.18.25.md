## Notification titles, legible

The log showed titles "written by gpt-oss-120b" — the generation succeeded; what failed was the
pipeline around a model that decorates and over-runs: markdown bold/backticks/"Title:" labels
survived to the Lock Screen, and an over-long line was silently word-trimmed into a fragment
("Only 124 steps so far — time"). Now: the cleaner strips the decoration; an over-long line gets
ONE corrective turn (its own line + the 32-char cap restated) before the trim remains as last
resort; and `Automation: … title — written by <model> — "<the actual text>"` puts the posted
title in the ledger, so the next log answers "what did it actually say".
