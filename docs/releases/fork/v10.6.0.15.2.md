## "How these were set"

A collapsed disclosure under the targets strip (both Today screens — the strip is shared). Five
caption lines, one per concern, with today's actual inputs filled in:

- **Session** (the shared input Effort and Cal price from): charge band → base minutes, readiness
  notch, Rest shift, final minutes @ Karvonen HR.
- **Effort**: minutes × Edwards zone weight = TRIMP → strain curve, with the frozen-target note;
  a rest day states the hold-don't-add rule and the "x/0" story.
- **Cal**: resting day (stated as target − session, exact on the displayed numbers) + Keytel
  session kcal, rounding named.
- **Steps**: band base (6k/8k/10k), readiness trim, 4k–12k clamp.
- **Sleep**: age-population base, each active adjustment (charge/Rest/readiness), the capped 25%
  debt term, 7–10 h clamp.

Built by the pure `TargetsExplainer` INSIDE `Repository.liveTargets`, from the same values the
pricing just used and carried on `LiveTargets.explainLines` — the section and the strip can never
disagree. Pinned by `TargetsExplainerTests` (session day: the stated TRIMP/kcal arithmetic must
reproduce the passed-in targets; rest day: rest wording, rundown step trim, no phantom debt term).
