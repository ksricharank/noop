## Coach typing and the keyboard

Reported: the keyboard was slow to come up, each character lagged again, and the floating tab bar
rode up with the keyboard and covered the field.

- Focus lives in `CoachComposerBar`. 19.10 read it in CoachView (dock padding, a scroll), so focusing
  re-evaluated the whole screen, re-parsing every reply's Markdown as the keyboard was asked to rise.
- Transcript rows are an Equatable leaf (`CoachTranscriptRow`): screen re-renders skip unchanged rows.
- `defaultScrollAnchor(.bottom)` keeps the latest reply in view as the keyboard shrinks the viewport.
- The tab bar hides while the keyboard is up (show/hide notifications only). Its glass sat over the
  field being typed into, re-sampling its backdrop every keystroke.
