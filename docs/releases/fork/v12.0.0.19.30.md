## Coach prompts: "Make this my default"

The maintainer: "for all the prompts in the coach section, give me an option to make my edited
prompt the default — so that I can make changes that you can then read when editing next".

Each of the eight coach prompts resolves through THREE layers: an edit in progress, then MY
DEFAULT, then the built-in. The editors share one action row (`PromptDefaultActions`):

- **Make this my default:** promotes the current edit and clears the edit it came from.
- **Restore built-in:** shown while a saved default exists; drops it.
- **Reset to default:** discards the edit. It reads "Reset to my default" while one is saved.

**How a build reads them.** The saved defaults live in the app's settings ON THE PHONE
(`<key>.myDefault`), not in the repo. So the strap-log header gains a **Coach prompts** section:
per prompt, the layer in force with fingerprints, and the FULL text of any saved default or edit
between `>>> MY DEFAULT — <key>` / `<<< END MY DEFAULT` markers. The maintainer asked whether the
log was needed; it is the only channel from the phone to the next build.

**Absorption.** When a build's built-in text equals a saved default (whitespace-insensitive),
`absorbMyDefaultsIntoBuild` at engine start retires the saved copy, so that build's later changes to
the prompt reach the wearer again. The synthesis retired-default fingerprints never apply to a saved
default, because it is the wearer's explicit choice.

## NSS: now vs typical, with the gap

The maintainer quoted the Today bullet: "your stress score is 18 right now, which is sitting right at
27 which is your typical". The block called anything within ±10 "about my typical", and the model
turned that into "sitting right at".

- `nssBandWord`: "about my typical" only within ±3. The words carry the gap, for example "a little
  below my typical, calmer than usual — 9 below my typical 27". The bands are well above (+10),
  a little above, about, a little below, well below (−10), and unusual (≥ 95th percentile).
- **NSS card pill:** WELL ABOVE TYPICAL / ABOVE TYPICAL / TYPICAL (±3) / BELOW TYPICAL /
  UNUSUAL FOR YOU.
- **Today prompt NSS bullet:** compare in the block's own words and gap, "never call two different
  numbers the same". The action comes only at "well above my typical" or "unusual for me".
  Retired default: `0x6272a1ab9b230dba`.
