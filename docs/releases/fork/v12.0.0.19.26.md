## NSS on the rest of the Insights tab, and a square NSS widget

The maintainer: "add NSS to the metrics row and year strip of the insights page, and add it to
relevant elements of the insights and what the trend says LLM sections … and yes create a new NSS
widget that varies through the day (should be a square widget)".

**Metric rows and calendar.** `MultiMetric.nss` is the daily average NSS: 0–100, lower is better,
amber. It joins both cards' default selections, and `MultiMetricPrefs.addNSSOnce` appends it ONCE to
a selection stored before it existed. There is a per-style flag, so removing it in the picker sticks.
The calendar treats it as already 0–100, like Charge and Sleep, inverted for lower-is-better.

**Coach reads on the Insights tab.**

- **What the trend says:** now EIGHT bullets. The eighth is `**Stress (NSS)**`, read with its
  direction (50 = usual, higher = more keyed up, experimental). With no NSS calc line it says the
  history is still building.
- **Both reads** (this one and the daily insight) get the window's NSS daily averages, with what the
  number means, plus a `Stress (NSS)` line in `perMetricTrendBlock`. The line is omitted when the
  store has no NSS, so the block reads exactly as before.

**Square NSS widget** (`NSSWidget`, `.systemSmall`).

- **Face:** NSS now / 100, band-tinted (blue < 33, green, amber ≥ 67), today's average, and today's
  curve over a dashed usual-at-50 line. The curve is drawn with the stress widget's own geometry
  (`StressTrace`, `StressCurveShape`) at NSS × 3/100, and breaks at gaps over 10 min. With nothing
  scored today it shows a dash and "No reading yet today", never a flat line.
- **Data:** `WidgetSnapshot` gains `nssSeries` (`NSSPoint`, 5-minute points thinned from the store's
  readings), `nssDay`, `nssNow` and `nssMean`, published with every full publish. The post-offload
  publish runs right after the quick pass that updates NSS. A finished day's curve is not drawn.
- **Budget:** NSS moves on every sync, so a reload request is made only when NSS now moves a 5-point
  step or the day changes. The curve rides along with any reload, and the widget's own 30-minute
  timeline picks it up regardless. Comparing the whole series would have spent a background reload
  per sync against a ~40–70/day budget.

Add it from the home-screen widget gallery: NOOP → "NSS".
