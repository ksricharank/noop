## Pulsing is back, capped at 6

19.37 removed Pulsing outright. On the wrist, Pulsing ×6 ended on its own; only ×8 kept the strap
buzzing until a Restart strap. So Pulsing returns with a **6**-repeat cap.

- Caps per style (`StrapBuzzPrefs.Style.maxCount`): Standard 8, Pulsing 6, Long and Longest 2.
- The cap applies where every 5/MG buzz is built (`StrapBuzzPrefs.cappedLoops`), not only to the
  notification count, so no in-session cue can play Pulsing past 6.
- A Pulsing ×8 setting stored by 19.36 now reads back as ×6.
- The stepper's help names the selected style's cap.
