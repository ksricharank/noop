## The Insights tab, led by a daily insight

The Trends tab is renamed **Insights** (tab label, sidebar, hosted-card source,
accessibility — the internal identifiers and persisted keys are unchanged). Its
existing content is untouched, including 438's seven-line trend summary.

New arrangeable section **Insights**, first in the default order, movable and
hideable in Arrange like every other card (on a previously saved layout the
append-missing recovery lands it at the bottom — move it up once). Pure text,
LLM-written, one insight per day (re-asked per local day; cached otherwise;
refresh button re-rolls):

- **Looking back** — one longitudinal story or a cross-metric pattern from the
  wearer's own history, preferring findings the gated INSIGHTS block already
  passed, cross-signal reads flagged as reads.
- **Looking forward** — "if you do X, Y will likely follow": X an action the
  wearer can actually take, Y anchored in their numbers, mechanism in one clause
  from established physiology, general knowledge welcome but flagged as such and
  never carrying invented numbers. No diagnosis, ever.

Engine: `dailyInsight()` reads a fixed 60-day slice — deliberately not the range
bar's window — fed wide day lines + the gated INSIGHTS block + perMetricTrendBlock.
Prompt is user-editable (Coach settings → "Daily insight instructions",
`ai.insightPrompt`); novelty is the stated job and the other four tab lenses are
fenced off so it never duplicates them.
