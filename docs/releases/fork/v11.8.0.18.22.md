# 11.8.0.18.22 (build 423)

The sedentary claim stops lying, and the digest can ship itself.

## "Sitting for 200+ minutes" — three defects, one line

The Today synthesis's sedentary line came from an HR-only heuristic with three stacked faults:

1. **The unobserved gap counted as sitting.** Minutes were measured to wall-clock now, but the
   samples end at the last strap offload. A strap that had not synced since lunch billed the whole
   afternoon as stillness.
2. **A calm window reported its whole length by design.** If HR never rose 15 bpm over the window's
   own floor, the code returned the entire 6-hour span — so an ordinary desk day was "200+ minutes"
   working as written.
3. **Steps were never consulted.** A walk that does not lift HR 15 bpm over the floor counted as
   sitting, despite the strap's locomotion counter saying otherwise.

`sedentaryRead` now anchors on the most recent step burst (`StepsCounter.lastMovementTs`, the same
wrap/plausibility/activity-class gates as the daily total; ≥10 locomotion ticks so wrist noise does
not count), falls back to the HR-rise rule, measures only over the observed span, and reports the
data's age: fresh → plain claim, 20–60 min stale → "as of the last strap sync (N min ago)", older →
the line is dropped. Pinned in the re-written `RecentStateBlockTests` (6) and
`StepsCounterLastMovementTests` (4, package).

## Muse: run a Shortcut after each write

> everytime the integration happens, an apple shortcut is run subsequently after a custom delay

On the Integration screen: a Shortcut name (blank = off), a delay (0–30 min; the delay exists so
iCloud Drive can upload the file first), and a Test-run button. Every digest write — scheduled,
catch-up, or "Generate now" — arms one pending run at write + delay.

The platform boundary, honoured rather than hidden: **iOS only lets the frontmost app launch a
Shortcut.** So: due while NOOP is frontmost → runs on time; due while backgrounded → the run stays
pending and fires at the first possible instant, i.e. the next sync hook or the next app open,
whichever comes first (the maintainer's requested fallback). One slot, overwritten by the next
write, never expiring. macOS always runs on time (NSWorkspace). Ledger lines: `integration:
shortcut "…" armed (+N min)` / `launched` / `due, app not frontmost — will run at the next
opportunity`.
