## Trends: seven lines, one insight per metric

437's single daily insight read as nonsense ("Charge 81 outpaces effort 24.4").
Revised format, per the selected window: ONE line each for **Charge, HRV, Resting
HR, Sleep, Effort, Steps, Day quality** — the bolded metric name plus a ≤20-word
interpretation (direction and duration; "held steady" is a legitimate line; "too
few readings" is passed through). The numbers come from a new on-device
`perMetricTrendBlock` fed to the model: per metric, the mean, newest-half vs
older-half, least-squares slope per week, extremes with their days, and |z| ≥ 2
anomaly days — the model reads trends, it no longer computes them. Re-asks on
window change and once per local day, as before. Override note: Reset to default.
