## Effort target moves with charge on primed days

Report: the effort target lands on a few discrete values (49, 56, 59 — never 57 or 58). Steps and
calories had gone continuous in 261004; effort had too, except at the top: the primed rung asks 4/3
of the base minutes, which passes the 60-min session cap from charge ~67 up. Every high-charge
primed day was therefore the same "60 min at zone-3", worth exactly 59.

Past the cap the session stays 60 min and the remainder comes as PACE: the Edwards weight and its
%HRR rise continuously from zone-3 (3, 75%) toward zone-4 (4, 85%), so the session is worth exactly
what the uncapped minutes would have been. Charge 67 → 59 (unchanged), 81 → 60, 100 → 62. The
calorie target and the session heart rate follow from the same session; "How these were set" says
when the ask has moved into pace. The remaining jumps between values come from readiness changing
level (balanced ↔ primed), which is a real change in the body read. The strain curve is
logarithmic, so even a large change in workload moves the target by only a few points.
