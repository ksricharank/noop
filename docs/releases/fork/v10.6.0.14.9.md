# Fork release 10.6.0.14.9 (build 271)

The island-less daytime mode (maintainer, 260830 midday: "I am tired of all these battery saving
optimizations"). New default operating mode: **Live Activity OFF, Continuous HRV ON + Overnight
only ON** — the strap streams only at night, daytime data arrives as ~15-minute offload bursts,
and the richer modes are opt-back-in when battery allows. This release builds the surfaces that
mode needs. One commit on the new `feature/targets-widgets` (STACKED on `feature/three-pillar-card`
— it reads `LiveTargets`/`cachedLiveTargets`; same re-homing obligation as the 260829 trio).

## What the two toggles actually turn off (the maintainer's "please confirm")

With Live Activity off + HRV overnight-only: no island/banner ever starts; the daytime realtime
stream is off in every phone state (the overnight window is the only stream time); the locked
duty-cycle averaging machinery is now explicitly gated on the Live Activity toggle too, so its
per-offload window query costs nothing; the breathe-cue evaluator is tick-driven, so it is dormant
whenever no stream runs (it still works at night). What stays: the BLE connection itself, the
~15-min offload bursts, post-offload scoring (with the 14.6 settle policy), and the widget snapshot
publish — which is the point.

## NOOP Targets: a second widget (kind `NOOPTargetsWidget`)

Same shared snapshot/provider as the existing rings widget, so the two can never disagree.

- **Lock Screen, above the clock** (`accessoryInline`): `Cal 180/450`.
- **Lock Screen, below the clock** (`accessoryRectangular`): HR · Cal · Sleep in one row.
- **Home Screen** (`systemSmall` rows / `systemMedium` columns): the same trio, plus the **strap
  battery in the top-right corner**.

HR here is the **burst average** — mean over the freshest 15 minutes of persisted samples,
anchored at the newest sample (a late publish still describes the burst, never an empty window),
abstaining ("–") past 2 h staleness. Deliberately NO tilde: the tilde means a live beat. Values
move at the burst cadence: the post-offload background publish (#980) rewrites the snapshot each
sync; repaints are subject to iOS's daily widget refresh budget, so an individual update can land
minutes late — by design, not a bug.

## Today: the targets trio above the narrative

`DailyTargetsStrip` on BOTH Today screens (liquid + classic), at the head of the Synthesis card,
before the LLM prose: HR (live `~72` when a beat is flowing, else the burst average), Cal
now/target, Sleep tonight — the same numbers the narrative, the card, and the widgets cite, big
and readable without reading the paragraph.
