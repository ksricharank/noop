carries 19.23 (NSS) and 19.24 (Integration times), none of them installed yet.

## NSS everywhere on the Stress tab, and on Insights

The maintainer: "add NSS to the insights and trends page as well, and also in the stress tab, replace
the 0-3 stress score with NSS everywhere relevant".

**Daily history.** `NormalizedStressStore` now keeps the daily average NSS for 400 days, in
`nss-v1.json` (`daily`, optional so the 19.23 file still decodes). The 14 window-history days are
re-scored against the current model on every update, so the days a trend compares share one model.
Today comes from its live readings. A day older than the window history keeps its last average. One
map, `Snapshot.dailyByDay`, feeds every trend below.

**Stress tab:**

| Was (0–3) | Now (NSS) |
|---|---|
| Stress Monitor gauge (the once-a-day score) | The NSS card as hero: now / 100, band, why, last high |
| Markers "Stress" tile + 14-day daily sparkline | "NSS" tile: now, band, 14-day sparkline of daily NSS |
| "Calm time": share of recent days in LOW | Share of today's scored NSS minutes in LOW (< 33) |
| Today's Timeline: hourly 0–3, avg/peak, Calm/Moderate/High hours | NSS line (5-min points), avg/peak, band totals in minutes (`StressTotals.unitMinutes`) |
| Sustained-high Breathe card (3 high hours) | Shown while a high NSS episode (≥ 67 for ≥ 10 min) is still running |
| Stress Trend: daily 0–3 | Daily NSS, 0–100, same range selector |
| "How this is computed": the 0–3 math | The NSS method and limits; bands 0–33 / 33–67 / 67–100 |

Kept as they were: the Resting HR and HRV markers (last night against the 30-day baseline, labelled
as such) and the Advanced HRV card. The hourly 0–3 read still runs, only because the Advanced HRV
card's R-R read rides it.

**Insights tab:** a new "Stress (NSS) trend" section, a `ScoreTrendSection` over the daily averages
with its own window. It is SHOWN by default (`canonicalOrder`, not in `defaultHidden`), so an existing
saved layout gets it appended at the end, where Arrange can move it.

**Coach:** the NSS block adds `daily averages, oldest first: …` for the last 14 days, so the Insights
and trend reads can talk about direction.

**Today:** the hosted "Stress through the day" card mirrors the Stress tab's NSS line, as it always
mirrored that tab's timeline. The Stress card value was already NSS (19.23).

Not changed: the home-screen stress widget still draws the hourly 0–3 curve (`StressDayCurve`).
