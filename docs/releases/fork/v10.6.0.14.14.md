## The maintainer's design (now the contract)

**Numerators move all day; denominators and the full reconciliation wait for the morning open.**

1. **Background light re-score** (`feature/background-light-rescore`): after any offload whose
   full pass was deferred (the debt is owed), run the SAME `analyzeRecent` at `maxDays: 2`
   (today + yesterday for the midnight boundary) inline under a background assertion. ~1/10th the
   window reads, so it finishes where the full pass measurably cannot. Byte-identical values for
   the days it scores (same code; baselines fold from stored history; eviction window-bounded).
   It never impersonates the full pass: no debt mark/settle (nil token), no
   `lastCompletedPassSeconds` (a 2 s light pass would teach the policy to un-defer the 21-day
   pass into a locked background), no #836 watermark advance, no `pendingForcedRescore` re-arm.
   Logs `trigger=light-today` → `re-score (light): done`. The deferred FULL pass still runs at
   the next foreground or granted overnight processing task — no data loss is possible either
   way: raw rows persist at offload time and scoring is re-derivable.
2. **FROZEN effort target** (`feature/targets-widgets`; maintainer: "freeze it"): the denominator
   is the prescribed session's worth alone, not "effort so far + session" — the riding form moved
   the goalpost all day ("8/67" instead of "8/59") while Cal/Steps/Sleep held morning values. A
   REST day now has NO effort target (displays degrade to the bare numerator), not "8/0".
3. **Reload thrift** (`feature/targets-widgets`): `renderedContentChanged` compares Cal/Steps/
   Sleep at DISPLAY granularity (the abbreviated pairs + "8h30" — the only forms any snapshot-fed
   face renders). With numerators now moving every sync, raw-int dedup would have burned ~90+
   WidgetKit reload requests/day against a background budget of ~40–70, deferring exactly the
   repaints that matter. Sub-display changes ("1712→1739 kcal") no longer ask for a repaint.

Pinned: rest-day invariant + frozen-target (RepositoryLiveTargetsTests), sub-display dedup incl.
the kAbbrev-rounds gotcha (WidgetSnapshotTests). Both app targets compile; affected suites green.
