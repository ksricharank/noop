## Coach is a tab; the bar is drawn by the shell

Coach sits between Insights and More. The native iPhone bar cannot show six, so NoopTabBar draws a
floating glass capsule, a little shorter and lowered 20 pt into the home-indicator band. The system
TabView keeps five pages — a sixth child makes UIKit build its own "More" list, which the simulator
showed — so Coach and More share the last page. The bar hides on pushed screens. The Coach More row
is gone; "Ask the Coach" opens the tab. The coach master switch hides the tab.

## Coach: a full-screen chat

Transcript fills the screen; replies run the full width as plain text; one scrollable prompt row
(follow-ups, then contextual, de-duplicated) over a single rounded composer; errors at the end of the
conversation; the privacy note only before the first question.

## Today read: Now = heart, calm, exertion over the last hour; Next leads with ideas

New default prompt. A stored copy of the 261006 default is recognised (fingerprint) and no longer
shadows it — no Reset needed. New MY LAST HOUR block (10-min HR, minutes 30+ above resting, peak,
steps, hour stress index). Fix: the six-hour HR read was capped at 8,000 rows ascending, i.e. the
OLDEST ~2.2 h — the newest hours never reached the model and the sedentary read was stale.
