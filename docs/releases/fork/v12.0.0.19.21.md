## Today stress bullet: always a level

The maintainer, on 19.20: the bullet kept saying there was no stress level, while the Stress
screen clearly showed one. In 19.20 the STRESS line took "now" from the newest timeline point. When
that point was masked as movement, or nothing had been scored in the last hour, it printed "no
reading". The chart, meanwhile, ends its line on the newest SCORED point, so it still showed a value.
The newest half-hour point covers an hour that has only just begun, so a short walk inside a thin
window was enough to mask it.

Now (`AICoachEngine.stressNowSummary`):

- **"Now" = the newest scored point**, the one the chart ends on. There is a level whenever anything
  today has been scored.
- **Moving:** when a NEWER point was masked as movement, the line adds `I am MOVING right now:
  movement is effort, not stress, so it is not scored, and the 'now' figure is my last settled
  reading, from N min ago.` The bullet says so in a few words and presents the figure as that.
- **Old:** a level older than an hour, with nothing masked since, says how old it is.
- No new metric: a moving hour is still never scored as stress.
- The bullet's figure form is unchanged: `(**X** now vs **Y** for the day, of 3)`. The 19.20
  default (`0xc5cf215929a2bf0f`) is retired.

**Instrumentation.** Each context build (synthesis or chat send) logs one line, for example
`coach: STRESS line — now=1.0 (latest scored, 30 min old) movingNow=true day=1.2/3h (timeline
points=… scored=… moving=…)`, or `coach: STRESS line absent — …` with the reason. If the bullet
still reads wrong, this line says whether the coach was given a moving point, an old one, or none.
