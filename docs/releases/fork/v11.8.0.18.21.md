## Apple Intelligence as a coach provider

> is it possible to wire up ondevice siri for the LLM coach … allow me to pick the most powerful
> model the iphone offers natively

**What the phone offers an app.** Apple exposes ONE model to third-party apps: the ~3B-parameter
on-device model behind Apple Intelligence, through the FoundationModels framework (iOS 26+). The
larger model the Siri beta uses for hard requests runs on Private Cloud Compute and is not callable
from an app in the iOS 26.5 SDK on this Mac — being on the Siri beta changes what Siri can do, not
what NOOP can call. So the "most powerful model the iPhone offers natively" is the on-device one, and
it is now a fifth provider in the Coach picker: **Apple Intelligence**. No key, no account, no
network. Hidden where the device cannot run it.

**Fitted to a small model, not just plugged in:**
- **4,096-token window.** Every request passes `OnDeviceContextBudget.fit` (8,000 characters of
  prompt + history): the oldest middle turns are dropped first; if the two anchors (the first turn
  with the data, the last with the question) still overflow, the longer one loses its middle and keeps
  its head (the newest day-lines) and its tail (the question or the tab's instruction), with a
  visible seam. A request the model still refuses for size is retried once at half the budget, then
  reported as "too much data … even after trimming".
- **An on-device rider** is appended to the coach instructions at send time — 180 words, verbatim
  numbers only, never invent a value, interpret rather than restate — without touching the editable
  prompt, so it applies only while this provider answers.
- **Failures named for the wearer:** a guardrail refusal ("declined under its safety rules"), a model
  still downloading, the background rate limit, a concurrent request.
- **Streaming and prewarm.** Apple's cumulative snapshots become append-only deltas, so Ask the
  Coach types out as it does on Gemini; the Coach screen loads the model on appear so the first
  answer does not also pay for the load.
- **Copy that is true:** Disconnect is hidden (nothing to disconnect from); consent and privacy lines
  say "read by Apple's on-device model, nothing leaves this iPhone" instead of "sent to the provider".

All four tab summaries, the Today synthesis, the morning brief, notification titles and the
follow-up chat go through the same `callProvider` / `streamProvider` paths, so switching the picker
switches everything. Gemini stays selectable for the deeper narratives.

**No Android twin** — FoundationModels is Apple-only. Fork-only surface, like the digest.
