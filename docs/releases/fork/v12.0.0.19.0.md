# 12.0.0.19.0 (build 436) — the v12 uplift, 261004

The v19 line: every fork branch rebased from upstream v11.8.0 onto the **v12.0.0 tag**
(359 commits), plus the 261004 feature batch. Cut 2026-10-04; replaces 11.8.0.18.31/432.

## Why now

Upstream v12 lands a raft of fixes aimed at exactly the background-grind problem the
18.31 canary gate was built for, all verified present in this assembly:

- **#2293** — a post-sync pass no longer re-scores nights and cycles whose inputs did not
  change: closed cycles are witnessed by two index-only queries (COUNT/MAX per owner)
  instead of a day of HR reads, and habitual sleep learns only from FINISHED nights, which
  kills the every-sync day-cache drop. This is the direct cure for the 261004-0703 log's
  morning treadmill (a 21-night debt re-scanning 7, then 14 unchanged nights at wake).
- **#2334** — an unfinished background re-score retries after a 30-minute cooldown instead
  of deferring forever (the fork's morning passes were that deferral's victim).
- **f7aaf78bc** — backgrounded offload re-scores are spaced ≥30 min apart.
- **#2607** — re-score admission is serialized before the first store await.
- **#2606** — a history repair's queued follow-up returns to the 21-day window.
- **549549ead** — HealthKit observer deltas are bounded to the recent sync window (the
  deferred fork item "narrow the write-back window 14d→2d" is retired: upstream did it).
- **#2525** — Charge baselines fold through one `ChargeBaselines` rule; **#2460** —
  upstream now carries its own effortHRmax override resolver (the fork's 18.25 port is
  retired as redundant).

## Fork changes in this build (besides the uplift)

- **Today synthesis**: the skeleton is now **Now / Next / Watch**. Now reads the STATE OF
  BEING from the immediate past (interpretation, never a readout) and explicitly feeds
  Next; Next absorbs Tonight — actions spread across the whole remaining day, anchored in
  words (after lunch, this evening, before bed), wind-down and the one "about HH:MM"
  bedtime included. Override note: a user-edited prompt shadows this default — Reset to
  default to pick it up.
- **Trends**: the tab summary now leads with **TODAY'S FIND** — one novel, bolded claim
  per day (novelty beats importance; yesterday's find must not be today's), and the card
  re-asks once per local day (subject gains the day key).
- The morning settle outranks upstream's new offload spacing: a window-deferral-only debt
  runs at the first post-window trigger (policy + pin test).
